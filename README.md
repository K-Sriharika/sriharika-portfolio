## 📂 Featured Projects

### 🔬 [Instagram Sentiment Analysis](https://github.com/K-Sriharika/Instagram-sentiment-analysis)
Empirical comparison of lexicon-based vs. LLM sentiment on 64 bilingual Hindi-English Instagram comments (41.4M aggregate views).

- **39.1% disagreement rate** between TextBlob and LLaMA 3; rises to **57%** on high Hindi-density content
- Identified 3 failure modes: Hindi vocabulary blindness, cultural sarcasm, Romanised abuse false positives
- Structural implications for RLHF pipelines using automated multilingual sentiment scoring

**Stack:** Python · TextBlob · VADER · Groq API (LLaMA 3) · Pandas · Matplotlib · WordCloud
